An entry for [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) on make.fun: one line, a pickup line an AI agent could actually say out loud to a person.

## How it works

`main.py` writes a single line to `/output/entry.txt`. The program is fully
deterministic — it produces byte-identical output on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
